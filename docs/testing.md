## 重现本地模拟

在仓库根目录运行 `node tests/fixtures/server.cjs`，打开 `http://127.0.0.1:8765/node/1/take?case=normal`。测试 Key 为 `sk-local-fixture-only-0000`，只用于模拟，不是实际凭据。

`case` 可选值：`normal`（两题与 Finish 前停止）、`multi`（多选子集、错误预选与混合题型）、`multi-all`（全选）、`multi-one`（仅一项正确的多选）、`review`（歧义弃答）、`low`（低置信度）、`invalid`（非法选项）、`auth`（401）、`unsupported`（错误分组）、`image`（图片附件）、`slow`（延迟响应，用于取消及切换题目测试）。

2026-10-27 的多选适配依据真实页面结构读取：`input[type=checkbox]` 的 name 形如 `question[QUESTION_ID][answer][user_answer][OPTION_ID]`，同题前缀相同而每项名称不同。测试使用合成题干与 ID，不包含个人测验记录。默认 `multi` 场景先错误勾选第 4 项，模拟响应选择前 3 项，用于验证取消错误预选。

先在本地页面保存虚构 Key，再点击对应解答按钮。用“切换测试题”模拟响应过期；不要输入真实 Key。测试服务不向外网转发请求。
